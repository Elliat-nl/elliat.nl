While this presentation is way too short to go into Prettier, a short rundown of how it works. It's DECLARATIVE!

  1. Parse code, stripping all whitespace
  2. Build a tree to determine where to place whitespace again
  3. Start printing: but whenever a group does not fit on a line, break it up where possible / allowed

See example

Now repeat this for all other places, choose where and how to break, and it's done!

🧪Dialects🧪

Experimental. Not fully implemented yet

Amending grammars

Take the XQ4 grammar

Parse it

Add new Rule to ExprSingle (for example)

Add definition for that Rule

Serialize to string

  1. Amending a grammar is also declarative
  2. Take the grammar and parse it using a parser generated by the REX parser generator
  3. Add a new rule to what you want to override (in the case of ExistDB update node: ExprSingle
  4. Add a definition of that rule
  5. Serialize everything to string again
const existDBMutations = [
	{
		where: 'ExprSingle',
		name: 'ExistDB_UpdateExpr',
		additionalRule: `ExistDB_UpdateExpr ::= 'update' (
  ExistDB_UpdateInsertExpr |
  ExistDB_UpdateReplaceExpr |
  ExistDB_UpdateDeleteExpr |
  ExistDB_UpdateRenameExpr |
  ExistDB_UpdateValueExpr
)`,
	},
];
